# 八爪鱼（Octopus）- AI智能体执行框架

## 项目简介

八爪鱼是一个开源的AI智能体执行框架，致力于实现从"思考"到"行动"的跨越，为大模型装上"手脚"，实现端到端的任务自动化执行。

## 当前版本

**v0.1.0 MVP** - 最小可行产品版本

### 已实现功能

- ✅ 命令行接入
- ✅ 大模型集成（支持OpenAI兼容API）
- ✅ 简单的对话功能
- ✅ 聊天历史管理

### 即将推出

- 🔄 多渠道接入（飞书、钉钉、微信）
- 🔄 执行平面（ReAct循环引擎）
- 🔄 能力层（技能系统）
- 🔄 行业适配系统
- 🔄 Web面板

## 快速开始

### 环境要求

- Python 3.8+
- pip

### 安装步骤

1. 克隆项目
```bash
git clone <repository-url>
cd 2603_03
```

2. 安装依赖
```bash
pip install -r requirements.txt
```

3. 运行程序
```bash
python src/main.py
```

### 使用说明

启动后，你将看到命令行交互界面：

```
==================================================
八爪鱼（Octopus）- AI智能体执行框架 v0.1.0
==================================================
输入 'exit' 或 'quit' 退出
输入 'help' 查看帮助信息
==================================================

用户> 你好
八爪鱼正在思考...

八爪鱼> 你好！我是八爪鱼，很高兴为你服务。有什么我可以帮助你的吗？

用户> exit
正在退出...
```

### 可用命令

- `help` - 显示帮助信息
- `exit` - 退出程序
- `quit` - 退出程序
